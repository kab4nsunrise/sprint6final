 Описание проекта: Конвертер азбуки Морзе

 Общее описание

Данный проект представляет собой веб-сервис на языке Go, который позволяет пользователям загружать файлы через HTML-форму и автоматически преобразовывать их содержимое между текстом и кодом Морзе. Сервис определяет тип содержимого (текст или азбука Морзе) и выполняет соответствующее преобразование.

Проект разработан в рамках учебного задания и демонстрирует базовые принципы работы с HTTP-серверами, обработкой форм, загрузкой файлов и автоматическим определением формата данных.

 Основной функционал

1. Загрузка файлов через веб-интерфейс — пользователь может выбрать файл через HTML-форму и отправить его на сервер.

2. Автоматическое определение типа данных — сервис определяет, содержит ли загруженный файл обычный текст или код Морзе, используя алгоритмы из пакета `service`.

3. Конвертация данных:
   - Если обнаружен обычный текст — он преобразуется в код Морзе.
   - Если обнаружен код Морзе — он преобразуется в обычный текст.

4. Сохранение результата — после конвертации создается локальный файл с преобразованным содержимым.

5. Визуальное отображение — пользователю возвращается результат конвертации в виде строки.

 Архитектура проекта

Проект состоит из четырёх основных пакетов:

 1. Пакет `server`
Отвечает за создание и настройку HTTP-сервера:
- Создание HTTP-роутера
- Регистрация хендлеров
- Настройка параметров сервера (порты, таймауты)
- Интеграция с логгером для логирования ошибок

 2. Пакет `handlers`
Содержит два HTTP-обработчика:
- Корневой эндпоинт (`/`) — отображает HTML-форму для загрузки файлов
- Эндпоинт `/upload` — обрабатывает загруженные файлы, выполняет конвертацию и возвращает результат

 3. Пакет `service`
Реализует логику автоматического определения типа данных:
- Анализирует входную строку
- Определяет, является ли она текстом или кодом Морзе
- Выполняет соответствующее преобразование
- Обрабатывает возможные ошибки

 4. Пакет `morse` (предоставлен)
Содержит готовые функции для конвертации:
- `ToText(morse string) string` — преобразует код Морзе в текст
- `ToMorse(text string) string` — преобразует текст в код Морзе
- Поддерживает русский алфавит для наглядности

 5. Основной пакет (`main`)
- Создаёт логгер
- Инициализирует сервер через пакет `server`
- Запускает сервер с обработкой фатальных ошибок

 Технические детали

- **Язык реализации**: Go
- **Стандартная библиотека**: используется для создания HTTP-сервера, роутинга и обработки форм
- **Порт**: 8080
- **Таймауты**:
  - Чтение: 5 секунд
  - Запись: 10 секунд
  - Ожидание следующего запроса: 15 секунд
- **Поддерживаемые языки**: русский текст и соответствующий код Морзе

 Использование

1. Запустить приложение
2. Перейти по адресу `http://localhost:8080`
3. Выбрать файл через HTML-форму
4. Отправить файл на обработку
5. Получить результат конвертации

 Примеры файлов

Эти файлы можно использовать для проверки работоспособности сервиса.

 Цель проекта

Данный проект демонстрирует понимание следующих концепций:
- Создание и настройка HTTP-серверов в Go
- Обработка HTML-форм и загрузка файлов
- Реализация логики автоматического определения формата данных
- Использование сторонних пакетов для конвертации
- Обработка ошибок и логирование
- Работа с файловой системой
